# 树图撤销、重做与移动端工具栏

- 可编辑知识树工具栏提供撤销、重做；快捷键 Ctrl+Z、Ctrl+Y（也支持 Ctrl+Shift+Z）。文本输入框保留原生文字撤销。
- 记录当前面板会话最近 100 次新增、修改、移动、排序、删除操作；刷新页面不恢复按钮历史。自定义只读 SQL 树不提供编辑撤销。
- 通过 knowledge/save 的 history 操作引用编辑 request_id，服务端保存字段差量。新增节点的撤销采用归档，不删除复习调度和评分；重做恢复原 ID。
- 其他设备修改同一节点或增加新子节点时，冲突拒绝覆盖；网络结果不明确时复用请求 ID 重试。不是整库回滚。
- 搜索框最小宽度 240px，工具栏溢出横向滚动；搜索和上/下匹配使用图标按钮，候选表上一页/下一页改为上下图标。
- Android 包包含前后端运行时；安装并重启手机服务后才能使用服务端历史能力。仅刷新旧服务网页不能升级 Python 后端。

验证采用临时数据库和 DOM 测试，不在真实学习主库创建测试节点或评分。
