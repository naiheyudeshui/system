# 查找当前操作的帮助 {#help}

本章说明当前统一帮助阅读器。自动验收使用真实 Study 前端与虚构数据，网页与软件内正文由同一份 Markdown 构建。

## 要完成什么 {#goal}

找到最近使用的插件、页面或控件说明，判断某项操作的作用与限制。

## 开始之前 {#prerequisites}

打开 Study 工作台，并先选中需要了解的插件。没有提供帮助正文的组件会明确显示缺失，不会自动生成不存在的操作说明。

## 操作步骤 {#steps}

1. 在需要了解的插件或控件上操作后，点击工具栏问号，查看当前简短提示。
2. 想持续阅读时，将问号拖到工作区边缘打开帮助窗格。帮助会尽量定位拖动前的来源。
3. 在目录中选择插件、页面或控件，也可以用搜索框查找已有帮助词条。
4. 选择“阅读完整说明”，在已有帮助窗格继续阅读；没有窗格时尝试创建，空间不足时使用内置阅读对话框。
5. 使用受众筛选、章节目录和全文搜索查找内容。左右箭头切换本窗格的阅读历史；窄窗格点击“☰”展开目录。
6. “返回来源章节”回到业务提示。原实例已关闭时会明确提示，静态说明仍可读；需要独立网页时再选择“在浏览器打开网页”。

## 完成后的结果 {#expected}

帮助不保存业务草稿、不提交复习评分。搜索同时列出短帮助与已发布手册的全文结果；每个全文结果带来源、版本和实际语言。进入完整手册后，Markdown 下载该版本的完整手册；还在短提示时下载帮助目录。缺少英文长文会标明中文回退，不会假装已经翻译。

## 没找到说明时 {#troubleshooting}

- 显示正文缺失：该组件尚未提供内容，可先阅读所属插件或工作台通用说明。
- 来源不准确：回到目标插件重新选择控件，再打开帮助。
- 详细链接不可读：检查插件当前启用状态和发布资源；不要为了测试帮助反复保存业务记录。
