# Study 插件操作说明 {#study-plugins}

适用于本产品当前交付的八个 Study 插件。先确认连接的是预期资料库；帮助、搜索和预览不等于保存。涉及保存、评分、计时、导入、删除的操作会改变当前服务器的数据。本文操作由源码核对，自动验收仅使用虚构数据；真实学习内容不用于测试。

## 表目录 {#catalog}

用途：找到表和视图，并将引用传给表格或打印插件。前提是服务器返回当前用户可读的对象目录。

1. 在启动器打开表目录，展开常用、外观视图或原始表分类。
2. 选择对象，已接入传输总线的接收窗格会读取该对象；需要指定目标时，将对象拖到目标网格或打印窗格。
3. 对比对象名称，确认接收窗格显示的是所选表或视图。
4. 收藏、展开和排列状态属于当前目录实例；另一目录实例应独立操作。

目录本身不保存一份网格数据。表格为空时检查接收窗格、对象权限及查询错误，不反复安装插件。展开一个分类不应把其他分类无限撑长；如果发生，记录窗格宽高、展开项目及截图，再使用帮助中的排错流程。

## 表格网格 {#grid}

用途：浏览收到的表/视图，执行产品允许的记录编辑。前提是已有目录传入对象，或当前实例已有有效对象配置。

1. 从表目录拖入对象，等待数据加载完成。
2. 核对表名、列与当前筛选，使用网格已有的筛选和分页控件定位记录。
3. 有编辑权限且该对象支持写入时，使用创建或单元格编辑入口。先检查预览与确认提示再保存。
4. 保存失败先读校验/冲突提示，取消不提交当前草稿。刷新更新当前实例的数据。

视图不一定可编辑；没有入口或被拒绝时不能直接修改其来源表来绕过约束。多网格实例按实例身份接收引用，不能把一格的选中对象当作另一格的绑定。查询结果范围不等于数据库全部记录；导出或打印前检查实际范围。

## 指标 {#metrics}

用途：查看今日到期、活跃卡片、章节节点、今日复习等统计；实际显示由已保存指标定义决定。

1. 打开指标窗格，等待统计加载。
2. 核对指标名称与当前资料库，在业务操作完成后使用公共刷新更新。
3. 若有指标管理入口，编辑 SQL 前确认统计含义并先预览；保存定义与读取数值是不同操作。

没有数据、查询失败和统计为零是三种不同状态。先检查错误和服务器连接，再判断是否真为零。窗格重复渲染不应产生重复指标订阅。指标是观察值，不是正式复习评分入口。

## 章节树图 {#tree}

用途：按方案预览并浏览知识层级，必要时编辑当前绑定的树。前提是方案返回稳定唯一的节点 ID、父节点引用及标题；新增或修改前确认当前服务器与数据来源。

1. 选择方案；先进入预览，检查根数量、最大深度、父引用警告和候选行。
2. 使用列筛选缩小候选集，或选择一个根查看子树。筛选作用于完整候选集，选根不会改写父子关系。
3. 选择“打开树图”。拖动画布平移、缩放，使用适应画布重新居中。切换大纲可阅读长正文。
4. 通过节点菜单查看详情。“以此节点为根”只改变当前视角；移动节点会改变层级或同级顺序。
5. 编辑时核对标题、正文和父节点，可预览 Markdown。保存写回原绑定数据；取消不提交。删除前核对目标与确认提示。
6. 使用上方返回箭头回到方案。公共刷新应保留列筛选和当前视图；树枝展开与正文展开是不同状态。

预期是当前方案显示所需分支。无正文节点不应展开空占位。预览出现重复 ID、缺父节点或环时先修复映射/来源，避免靠放大画布掩盖错误。保存冲突时重读当前记录，保留自己的草稿再处理，避免重复创建。配置字段问号解释的是取数、映射和校验，不会替你保存配置。

## 表格复习 {#review}

用途：从选定章节或方案开始一轮学习并保留真实评分。前提是方案提供稳定 card_id、题目和答案，已确认目标章节及卡片集合。

1. 选择复习方案，预览题目和数量，必要时使用列筛选或根节点限制子树。
2. “继续上次复习”恢复原会话及其卡片集合，不会自动换成新选章节。
3. 要学习当前确认集合，选择“开始一轮学习”。新会话不删除旧评分。
4. 先回忆，再显示答案；按实际回忆选择不记得、困难、良好或简单。评分会写入正式复习记录并推进会话。
5. 返回方案保留已完成进度。重新进入时核对会话和题目，避免把恢复会话误认为切换章节。

预览/保存方案不会写评分。集合异常先检查 SQL 参数、根节点和列映射；不要通过测试点击制造正式复习记录。断线或请求失败后先确认服务器状态再重试评分，不能假定失败提示代表服务端一定未保存。

## 番茄钟 {#pomodoro}

用途：记录专注任务。前提是已确认事项、项目和时长；只在真实专注时开始，不使用真实资料库做自动化演练。

1. 打开番茄钟，核对事项、项目和时长。
2. 点击“开始”，观察进行中状态和剩余时间。
3. 需要中断时暂停，恢复时继续；完成或放弃前核对当前任务及提示。
4. 再次打开或刷新时从服务器同步当前状态。打开帮助不会启动、暂停或结束计时。

计时状态属于服务器任务，两个显示窗格可能观察同一活动任务，不能把它理解成两份独立计时数据。尺寸变化只改变展示，不应创建新任务。时间不符先检查服务器连接与同步结果；浏览器后台节流时以服务器状态为准。

## 秒表 {#stopwatch}

用途：按实际活动记录经过时间和计次。前提是服务器可用、已核对当前活动任务。

1. 无活动计时时选择“开始”；运行中可“暂停”或“计次”。
2. 暂停后使用“继续”恢复；“重置”前确认当前记录和界面提示。
3. 重新打开时等待状态同步，再判断是否需要新的操作。

开始、暂停、计次和重置都是业务操作。数字跳动是显示，不等于每秒写入一次数据库。计次不可用时先看当前是否运行；不要靠刷新重复创建计时。多窗格查看同一任务时会共享服务器任务状态。

## 库同步与迁移 {#library}

用途：备份资料库或迁移知识树。前提是确认当前连接目标，导入替换前已有可恢复备份。

1. “导出完整 ZIP 备份”包含资料、复习记录、计时、已保存主题和托管附件。
2. “仅导出 SQLite”只含数据库，不含外部图片或 PDF，不能用来替代完整附件备份。
3. 迁移单棵内置知识树时，选择根并导出知识树 ZIP；导入为副本，不替换原树。包包含对应节点、复习进度、历史、范围与附件，不含进行中的会话、任意 SQL 方案或无关计时。
4. 整库导入选择文件，阅读校验结果与恢复选项，再明确确认替换。完整 ZIP 恢复后插件停用，需要重新授权。
5. 导入完成重新核对目标库、节点与附件。不得因文件被选中就认为恢复成功。

单树逻辑数据上限 8 MiB，超限使用整库 ZIP。未保存到资料库的浏览器主题不在备份中。恢复失败保留原文件与错误提示，不反复覆盖；不要将多个来源的 SQLite 与附件目录随意混装。

## 通用故障记录 {#diagnostics}

记录发生时间、插件和实例、来源对象或方案、窗格宽高、执行动作、可见错误码。界面截图使用虚构或脱敏数据。插件挂载/尺寸通知属于宿主接口日志；插件内部计算属于模块日志；布局数值采样可导出作对照。没有启用诊断时不要声称后台已记录全部前端点击。修改浏览器大小与只拖窗格分隔条需要分别复现，才能判定尺寸信号来自哪里。
