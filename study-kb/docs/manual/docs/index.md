# Study：从内容到复习 {#overview}

Study 用来组织知识、查看章节、按方案复习和记录专注时间。章节浏览与复习使用同一套产品数据；查看帮助不会创建知识、开始计时或提交评分。

这份产品说明补充工作台通用操作。插件安装、权限、窗格管理属于工作台说明；Study 的章节方案、复习和计时流程属于产品说明。现在可以从 [使用帮助](user/help.md) 开始。

软件内帮助、独立网页和 Agent Markdown 由这些作者源统一生成。当前交付插件的用途、步骤与限制见[插件操作说明](user/plugins.md)，树图和复习的字段解释见[数据方案配置](user/configuration.md)。问号保留短提示，选择完整说明可在帮助阅读器继续查看；每篇显示实际文档版本和语言。没有发布全文的第三方插件仍明确显示缺失状态。
