# 树图拖拽插入（2026-10-17）

## 实现

保留卡片上方/下方 28% 插前/插后、中间区域移为子节点的规则。
空白区则以源节点真实 parent_id 的可见同级卡片矩形进行碰撞判断：

- 两卡片间空隙按中点分配到上卡片之后或下卡片之前。
- 第一张卡片上方、最后一张卡片下方增加 64 CSS 像素的命中区。
- 横向限制在卡片矩形左右各扩展 24 CSS 像素内，远处空画布不命中。
- 排除拖拽影子和源节点；原有禁止移动到自身后代的保护不变。
- 空白区只调用既有 onReorder，不引入数据库接口或实时写入。

拖拽期间使用 SVG path 展示待选父节点到拖动卡片标题左侧中点的虚线，以及目标插入位置实线。
两种预览线均使用 UI 的 --accent 主题色。连线保留拖拽抓取偏移，不追踪鼠标自身。
坐标由屏幕矩形转换为 SVG viewBox 坐标；线条忽略指针事件。
松手、取消及切换双指缩放时，沿用 clearDropPreview 清理预览。
没有可见父节点时不画父节点连线。

  拖放碰撞检测与排序反馈的设计参考；本项目沿用原生 Pointer Events，
  不引入 React/dnd-kit 依赖。
