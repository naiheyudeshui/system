# 窗格移动与页面状态保留（2026-11-02）

## 原因与方案

移动把手原来覆盖在插件右上角，手机触摸区与设置按钮重叠。改为顶部中央 80×24px 长条，内部六点横排为两行、每行三个，以 CSS 绘制固定布局，避免字体字形改变方向。根据用户实机反馈，顶部仅留 12px，另一半叠在内容上，减少空白。按下即高亮整个源窗格，取消、松开、失焦及销毁均清理；目标预览继续表达最终落点。

宿主在窗格跨越 presentation 条件时销毁旧 panel，导致树图返回方案页，复习页面、输入草稿等也可能丢失。尺寸变化应更新呈现，不应结束插件实例。相同 renderer 保留 panel；updatePresentation 接收新的形态信息；真正更换 renderer 或卸载插件才销毁。

Android Activity 原来在横竖屏或屏幕尺寸配置变化时也会重建整个 WebView。应用自行处理这些配置变化，保留同一个 WebView，让窗格尺寸观察器执行原位更新。

## 实施顺序

1. 中央把手与独立空间；整窗格反馈；检查鼠标、触摸、取消及键盘。
2. 宿主保留相同 renderer 的 DOM 与闭包状态；异步挂载后补发最新形态，避免初始化竞争。
3. 树图原位切换图形/大纲，保留详情、根节点、展开和相机；复习保持题目、答案显隐、筛选及编辑草稿。
4. 检查计时、指标、目录、表格、打印、同步、触发器与安装插件；需要不同布局的实现原位更新，纯 CSS 布局保留 DOM。
5. 自动回归及浏览器验证后构建 APK；备份手机数据、覆盖安装、实际触摸与状态验证，核对学习记录未变。
