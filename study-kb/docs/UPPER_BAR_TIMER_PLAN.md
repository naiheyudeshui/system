# 上栏插件与专注计时升级计划

## 目标

将现有插件布局从“顶栏 / 下栏 / 未启用”扩展为“顶栏 / 上栏 / 下栏 / 未启用”。现有指标区域改造成通用上栏插件宿主，指标本身成为普通插件；新增番茄钟和正向计时器插件。

## 术语与边界

- 顶栏：切换后替换中间表格区域的完整页面插件，可放多个并排序。
- 上栏：位于顶部导航和主工作区之间的轻量长条插件，只允许一个。
- 下栏：位于右下检查器区域的辅助插件，可放多个并排序。
- 未启用：插件不挂载到界面，但插件已有配置和历史数据保留。
- 轻量插件：清单中至少有一个 `location: upper` 面板。轻量插件只能进入上栏或未启用，避免长条界面被错误放入完整页面或检查器。

## 布局模型

布局数据升级为：

```json
{
  "top": [],
  "upper": ["study.metrics"],
  "bottom": [],
  "disabled": ["study.pomodoro", "study.stopwatch"]
}
```

兼容读取旧布局时自动补齐 `upper`，但保存后只写新格式。上栏校验要求最多一个插件，且必须声明 `location: upper`。拖入第二个上栏插件时，原上栏插件自动移动到未启用区；一次请求内完成，避免短暂出现两个上栏插件。

## 插件设计

### 指标插件 `study.metrics`

- 默认上栏插件。
- 复用现有指标查询、增删、编辑和折叠逻辑，不改变指标 SQL 与配置格式。
- 插件被停用后指标定义仍保留，重新启用后继续使用。

### 番茄钟插件 `study.pomodoro`

- 默认 25 分钟，可在开始前调整 1–120 分钟。
- 必填“所做事宜”；支持开始、暂停、继续、提前完成、放弃。
- 倒计时以服务端绝对时间和累计时长计算；浏览器定时器只刷新显示，后台标签页节流不会造成累计误差。
- 到时自动完成并写入结束时间。

### 计时器插件 `study.stopwatch`

- 正向累计计时；必填“所做事宜”。
- 支持开始、暂停、继续、完成、放弃。
- 刷新页面或更换上栏插件后，重新启用时可从数据库恢复当前会话。

## 数据模型

新增 `study_time_session`：

- `id`：会话 ID。
- `timer_kind`：`pomodoro` 或 `stopwatch`。
- `task_text`：所做事宜。
- `status`：`running`、`paused`、`completed`、`abandoned`。
- `planned_seconds`：番茄钟计划时长；计时器为空。
- `elapsed_seconds`：暂停或结束时已累计秒数。
- `started_at`、`last_resumed_at`、`ended_at`：ISO 时间。
- `abandoned`：是否放弃。
- `created_at`、`updated_at`：审计时间。

同一种计时器最多一个运行或暂停会话。服务端对开始、暂停、继续、完成、放弃做状态校验；客户端不能直接写表。

## API

- `GET /api/study/time?kind=pomodoro|stopwatch`：当前会话和最近历史。
- `POST /api/study/time`：`start`、`pause`、`resume`、`complete`、`abandon`。
- 局域网写入继续复用工作台现有写权限门。

## UI 与响应式

- 上栏插件统一使用现有面板、边框、主题变量和折叠把手。
- 桌面端横向排列任务、时间、进度与操作。
- 手机端允许分成两行，但不产生页面级横向滚动。
- 运行中使用主题强调色；暂停使用警告色；放弃按钮使用危险色边框而非实心遮挡。
- 插件管理器改为四个区域，上栏区域为单槽；拖拽替换时显示明确说明。

## 验收标准

1. 旧布局无报错升级，现有顶栏和下栏顺序保持。
2. 上栏只能保存一个轻量插件；替换后原插件进入未启用。
3. 非轻量插件不能拖入上栏，轻量插件不能拖入顶栏或下栏。
4. 指标以插件身份默认显示，原有指标管理功能可用。
5. 番茄钟刷新页面后时间准确，可暂停、继续、完成、放弃。
6. 计时器刷新页面后时间准确，可暂停、继续、完成、放弃。
7. 每次完成或放弃均记录开始、结束、状态、所做事宜与实际时长。
8. 桌面和手机界面均不产生页面级横向滚动。
9. 插件布局、计时状态机、HTTP 接口和前端主要交互均有自动化测试。
10. 不覆盖用户当前数据库、知识卡片或其他未提交开发改动。

## 实施结果

- 状态：`completed`
- 布局：已增加 `upper` 单槽位；指标默认位于上栏，番茄钟和计时器默认未启用。
- 替换：拖入新的上栏插件时，原上栏插件在同一次布局保存中进入未启用区。
- 数据：已增加 `study_time_session`，支持运行、暂停、完成、放弃和历史记录。
- 接口：已增加 `GET/POST /api/study/time`，局域网写入沿用现有写权限门。
- 回归：布局、计时状态机、真实 HTTP 路由、前端控件生命周期和上栏拖拽均有自动化覆盖。
- 运行验证：真实数据库布局已持久化为四组；指标启用，番茄钟和计时器停用；未生成测试计时记录。
